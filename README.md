# Python Essentials

A hands-on Python learning repo — core concepts explained simply, each paired
with a small, runnable **mini project**. Learn Python by building.

## Why this repo
Most tutorials either explain concepts with no code, or give code with no
explanation. Here you get **both**: short, clear notes + minimal, runnable
projects you can read, run, break, and rebuild.

## What's inside

| Topic | What you'll learn | Mini Project | Status |
|---|---|---|---|
| Basics & Syntax | Variables, types, operators, I/O | Number guessing game 
| Control Flow | `if/else`, `for`, `while`, `break/continue` | FizzBuzz, prime checker 
| Functions | Arguments, `*args/**kwargs`, scope, lambda | Utility toolkit 
| Data Structures | Lists, tuples, sets, dicts, comprehensions | Word frequency counter 
| Strings & Files | Formatting, `re`, file I/O | Log parser 
| OOP | Classes, inheritance, dunder methods | Bank account system 
| Exceptions | `try/except`, custom exceptions | Input validator 
| Modules & Packages | Imports, `pip`, virtual environments | Mini package 
| Iterators & Generators | `yield`, lazy evaluation | Data stream reader 
| Decorators | Functions as first-class objects, `@decorator` | Timer / logger decorator 
| Type Hints | `typing`, clean typed code | Typed data model
